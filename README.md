
# Office Management & IT Helpdesk Analytics

An integrated application for managing employee information, IT assets, and helpdesk operations, with data analytics features.

## Project Objectives

- Manage employee information.
- Track IT assets and equipment.
- Record and monitor IT support tickets.
- Store and manage operational data.
- Analyze IT support performance.

## Technologies

- Java
- Oracle SQL / SQLite
- Python
- Pandas
- Matplotlib
- Git & GitHub
